First public release of **NowPlayingBar**: see what's playing right inside the Windows 11 taskbar, with previous, play/pause and next buttons.

## Features

### Taskbar player
- Cover art, title and artist embedded in the taskbar, with ⏮ ⏯ ⏭ buttons.
- Works with any player that uses Windows media controls: music apps, YouTube Music, YouTube in the browser, foobar2000 and more.
- Follows the taskbar color automatically and re-attaches itself if Explorer restarts.
- Horizontal and vertical taskbars. On vertical taskbars, long titles scroll.
- Drag it to change its position; it remembers where you left it.

### Smart player selection
- **Music first:** if music and a video (for example, a movie in the browser) play at the same time, the bar shows the music.
- Among several players, the one that is playing wins, and the bar doesn't jump away while it keeps playing.
- **Source** menu: keep it on **Automatic** or always show one specific app.

### Smooth song changes
- The previous song stays on screen, dimmed, until the new one is ready (no "Nothing playing" flash).
- New title and cover art appear together. If the cover takes longer than 1 second, or the song has none, the player's icon is shown.

### Multiple monitors
- Choose a screen or **All screens** from the right-click menu, or drag the bar to another taskbar.
- In **All screens** mode, connecting or disconnecting a monitor adds or removes its bar.

### Menu and settings
- Right-click menu in the Windows 11 dark style: rounded corners, Fluent icons and toggle switches.
- **Start with Windows** (on by default).
- **Languages:** English, Español, Deutsch, Português (Brasil) and Русский. Follows the Windows language, or pick one from the **Language** menu.

### Installer
- No administrator rights or .NET install needed.
- Translated into the same 5 languages.
- Optional start-with-Windows and desktop shortcut.

### Privacy and safety
- Doesn't connect to the internet and doesn't inject code into any process. It only uses public Windows APIs.
- Built by GitHub Actions directly from this source code.
