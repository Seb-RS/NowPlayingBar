## Added
- **Smooth song changes.** When the song changes, the previous one stays on screen dimmed instead of showing "Nothing playing".
- **Music first.** If music and a video (for example, a movie in the browser) play at the same time, the bar shows the music.

## Changed
- New title and cover art now appear together. If the cover takes longer than 1 second (or the song has none), the player's icon is shown.
- If the player disappears for a moment while changing tracks, the bar waits up to 3 seconds before showing "Nothing playing".

## Fixed
- "Object reference not set to an instance of an object" error when changing tracks or closing a player.
- The player icon no longer flashes for one frame between songs.
- Some players send the new title with the previous cover first; this is now detected.
- Unexpected errors no longer show the .NET error dialog: they are written to `%APPDATA%\NowPlayingBar.log` and the app keeps running.
