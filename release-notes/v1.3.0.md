## Added
- **Languages:** English, Español, Deutsch, Português (Brasil) and Русский.
  - The app follows the Windows language (English if it isn't one of these).
  - New **Language** menu to pick one manually; the app restarts to apply it.
- The installer is translated too and asks for the language at the start.

| File | Description |
