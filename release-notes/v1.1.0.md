First public release of **NowPlayingBar**: see what's playing right inside the Windows 11 taskbar.

## Added
- Cover art, title and artist embedded in the taskbar.
- Previous, play/pause and next buttons.
- Works with any player that uses Windows media controls (music apps, browsers and more).
- Drag the bar to change its position; it remembers it between sessions.
- Multiple monitors: choose a screen or **All screens** from the right-click menu, or drag it to another taskbar.
- Follows the taskbar color automatically and re-attaches itself if Explorer restarts.
- Own logo and app icon.
- Installer (Inno Setup) with optional start-with-Windows and desktop shortcut. Self-contained: no .NET install needed.
- Experimental widget for the Windows Widgets board (Win + W).
- Automatic builds and releases with GitHub Actions.
